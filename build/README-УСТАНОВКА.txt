SMART CURSOR — КАК ЗАПУСТИТЬ
============================

1) Перетащите «Smart Cursor.app» в папку Applications (ярлык справа).

2) ПЕРВЫЙ ЗАПУСК — только так:
   Программы → правый клик по «Smart Cursor» → «Открыть» → «Открыть».
   Двойной клик в первый раз macOS заблокирует, потому что приложение
   не подписано платным сертификатом Apple. Это делается один раз.

   Если окно «Не удалось проверить разработчика» уже появилось:
   Системные настройки → Конфиденциальность и безопасность →
   вниз → «Всё равно открыть» → пароль Mac.

3) Разрешения (без них ассистент не видит текст и не вставляет ответ):
   • Универсальный доступ (Accessibility) — обязательно.
   • Запись экрана (Screen Recording) — чтобы отвечать по скриншоту.
   Окно со ссылками на эти настройки откроется само при первом запуске.

4) Ключ API: иконка в строке меню → «Настройки…» → провайдер
   (OpenRouter / [OI] / Anthropic) → вставить ключ → «Проверить».

КАК ПОЛЬЗОВАТЬСЯ
----------------
• Alt + Space — ассистент открывается рядом с курсором.
• Клик по иконке в строке меню — то же самое.
• Приложение живёт в строке меню, в Dock его нет.
  Выход: иконка в меню → «Выйти из Smart Cursor».
• Ярлык на Рабочем столе просто запускает приложение, если оно не запущено.

УДАЛЕНИЕ
--------
Перетащите «Smart Cursor» из Applications в Корзину.
Ключи и настройки: ~/Library/Application Support/smart-cursor
