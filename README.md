# Deskhand

AI-ассистент для macOS, который открывается рядом с курсором. Выдели текст, чтобы перевести его или подготовить ответ. Спроси, куда нажать, и Deskhand покажет на экране. Включи режим «Агент», чтобы поручить ему действия в приложениях.

## Первый запуск

1. Распакуй ZIP и перенеси `Deskhand.app` в «Программы».
2. Открой Deskhand, дай ему «Универсальный доступ» и перезапусти. Для скриншотов разреши запись экрана, для голосового ввода — доступ к микрофону.
3. Выбери OpenAI, OpenRouter или Anthropic, укажи ключ API и модель. Для скриншотов нужна модель с поддержкой изображений.

## Горячие клавиши

- **⌥ Space** — открыть карточку.
- **Enter** — отправить запрос.
- **⌘ Enter** — вставить ответ в активное приложение.
- **⌥ ⇧ Space** — удерживай, пока говоришь. Русская речь распознаётся офлайн.
- **Esc** — остановить агента.

В карточке можно убрать выделенный текст или скриншот из запроса к модели.
