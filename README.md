# Deskhand

AI-ассистент для macOS, который открывается рядом с курсором. Выдели текст, чтобы перевести его или подготовить ответ. Спроси, куда нажать, и Deskhand покажет на экране. Включи режим «Агент», чтобы поручить ему действия в приложениях.

## Установка

Нужна macOS 14 или новее. Одна команда в Terminal:

```sh
curl -fsSL https://github.com/BobrAll/deskhand/releases/latest/download/install.sh -o /tmp/deskhand-install.sh && bash /tmp/deskhand-install.sh
```

Установщик скачает последний релиз, проверит SHA-256 и подпись, положит `Deskhand.app` в «Программы». Если Terminal не подходит, скачай DMG со страницы релизов — ручная установка и обход предупреждения macOS описаны в [docs/install.md](docs/install.md).

После первого запуска дай Deskhand «Универсальный доступ» и перезапусти. Для скриншотов разреши запись экрана, для голосового ввода — доступ к микрофону. Потом выбери OpenAI, OpenRouter или Anthropic, укажи ключ API и модель. Для скриншотов нужна модель с поддержкой изображений.

Обновление — та же команда установки. Настройки и ключи сохраняются.

## Горячие клавиши

- **⌥ Space** — открыть карточку.
- **Enter** — отправить запрос.
- **⌘ Enter** — вставить ответ в активное приложение.
- **⌥ ⇧ Space** — удерживай, пока говоришь. Русская речь распознаётся офлайн.
- **Esc** — остановить агента.

В карточке можно убрать выделенный текст или скриншот из запроса к модели.

## Приватность

Телеметрии нет. Наружу уходят только запросы к выбранному провайдеру модели, поисковые запросы через него же и текст в сервис синтеза, если ты его включил.

В `~/Library/Application Support/Deskhand` локально лежат настройки, ключи API (шифруются через Keychain, когда он доступен), голосовые модели и агрегированная трасса `agent-trace.jsonl`. В трассе только тайминги и счётчики — без промптов, набранного текста, заголовков окон и скриншотов.

Подробные журналы запусков (`agent-runs/`, `agent-dialogs/`) выключены по умолчанию. Включай их в «Настройки → Приватность → Данные на Mac» только для отладки: они содержат промпты, заголовки окон и скриншоты, и делиться ими нельзя.

Удалить всё, что Deskhand сохранил на Mac: закрой приложение и удали папку `~/Library/Application Support/Deskhand`.
