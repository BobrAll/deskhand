# Установка Deskhand

Deskhand не подписан платным сертификатом Apple, поэтому macOS предупреждает при первом запуске непривычным образом. Это ожидаемо: приложение собирается из этого репозитория, а рядом с архивом лежит контрольная сумма.

Нужна macOS 14 или новее.

## Одной командой

Открой Terminal («Программы» → «Утилиты» → Terminal) и вставь:

```sh
curl -fsSL https://github.com/BobrAll/deskhand/releases/latest/download/install.sh | bash
```

Установщик скачает последний релиз, проверит SHA-256, положит `Deskhand.app` в «Программы», снимет карантин и запустит приложение. Пароль Mac понадобится, только если папку «Программы» нельзя изменить без него.

Если GitHub не открывается, укажи зеркало: `DESKHAND_RELEASE_URL="https://…" bash /tmp/deskhand-install.sh`. Зеркало должно отдавать те же `Deskhand-universal.zip`, `.sha256` и `install.sh`.

Если не хочешь запускать скрипт вслепую, скачай его, посмотри и запусти отдельно:

```sh
curl -fsSL https://github.com/BobrAll/deskhand/releases/latest/download/install.sh -o /tmp/deskhand-install.sh
less /tmp/deskhand-install.sh
bash /tmp/deskhand-install.sh
```

## Вручную

1. Скачай `Deskhand-universal.dmg` или `Deskhand-universal.zip` со страницы релизов.
2. Открой DMG и перетащи `Deskhand.app` в «Программы». ZIP сначала распакуй.
3. Запусти Deskhand из «Программ».
4. macOS скажет, что не может проверить приложение. Нажми «Готово» или «Отмена», но не «Переместить в Корзину».
5. Открой «Системные настройки» → «Конфиденциальность и безопасность» и прокрути вниз до раздела «Безопасность».
6. Нажми «Всё равно открыть» рядом с Deskhand, подтверди Touch ID или паролем, затем нажми «Открыть».

Кнопка «Всё равно открыть» появляется примерно на час после попытки запуска. Если её нет, запусти Deskhand ещё раз и сразу вернись в настройки.

На macOS 14 и раньше работал правый клик → «Открыть». На macOS 15 и новее этот способ больше не обходит Gatekeeper.

Если Terminal не пугает, карантин можно снять точечно:

```sh
xattr -dr com.apple.quarantine /Applications/Deskhand.app
```

Если macOS не даёт изменить приложение, добавь `sudo` перед командой.

Не отключай Gatekeeper для всей системы: это снижает защиту всех приложений, а не только Deskhand.

## Разрешения

1. **Универсальный доступ** — без него Deskhand не читает выделенный текст и не управляет приложениями. После выдачи перезапусти Deskhand.
2. **Запись экрана** — нужна для скриншотов. macOS может попросить перезапустить приложение ещё раз.
3. **Микрофон** — нужен для голосового ввода.

Разрешения привязаны к подписи приложения. Сборки Deskhand подписаны одним локальным сертификатом, поэтому обновления сохраняют доступ. Если ты переходил с совсем старой неподписанной сборки, один раз удали старое приложение из списка «Универсального доступа» и добавь новое.

## Обновления

Повтори команду установки или скачай новый DMG. Настройки, ключи и модели в `~/Library/Application Support/Deskhand` остаются на месте.

## Проверка архива

В папке с релизом лежит `Deskhand-universal.zip.sha256`:

```sh
shasum -a 256 -c Deskhand-universal.zip.sha256
```

Если сумма не совпала, скачай архив заново.

## Удаление

Закрой Deskhand, удали `Deskhand.app` из «Программ» и папку `~/Library/Application Support/Deskhand`.
