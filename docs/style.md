# Deskhand — цвета и стиль

Коротко: **белый текст и синий акцент на нейтральном стекле**. Второго акцентного
цвета нет. Новый элемент берёт токены из `src/renderer/styles/base.css` и не
вводит собственный оттенок — именно из-за этого свечение агента сначала выбилось
из палитры тёплым коралловым, а теперь использует тот же синий, что карточка,
рисовальный слой и индикатор «слушаю».

Документ — источник правды для цветов и базовых правил оформления. Если нужен
новый оттенок, сначала правка здесь, потом код.

## 1. Палитра

Светлая тема — не «другая палитра», а те же роли с более тёмным синим: на белом
фоне `#4a68f0` даёт нужный контраст, `#7b95ff` — нет.

### Слои у курсора

Свечение агента лежит поверх произвольного контента (белый документ, тёмный
редактор, фото), поэтому его цвета не зависят от темы: светлая панель исчезла бы
на белом. У него свои токены, но тот же синий:

| Слой | Токен | Значение |
| --- | --- | --- |
| Свечение агента | `--cursor-accent` | `#5b78ff` |
| | `--cursor-text` | `#f4f5f7` |
| Призрак указателя | `--ghost-ink` | `255 255 255` |
| | `--ghost-accent` | `127 149 255` |
| Рисование | `--ink` | `#5b78ff` |

Кольцо цели, всплеск клика и тень призрака берут синий из `--ghost-accent`:
он объявлен в `presenter.css` каналами `127 149 255`, а все три правила читают
`rgb(var(--ghost-accent) / …)`. Это не второй акцент, а тот же синий курсора,
осветлённый до читаемости тонкой линией: метки живут доли секунды поверх любого
фона и не должны спорить с элементом, на который указывают. Поэтому токен и не
входит в тему — он не меняется со светлой и тёмной панелью, иначе на белом
документе метка стала бы невидимой.

Индикатор «слушаю» — не отдельный слой: на время записи карточка заменяет поле
ввода пятью столбиками, теряет стекло, рамку и тень, а сами столбики берут
`--accent` из темы (на распознавании акцент снимается — там `--text-dim`, потому
что микрофон уже закрыт). Отдельного окна-индикатора нет — у курсора живёт только
свечение агента.

Фраза агента о том, что происходит, живёт в строке агента на карточке
(`.agent-label`), а не подписью у указателя. У указателя остаётся только галочка
завершения: справа снизу, с отступом 10 pt, без плашки; у края экрана она
смещается в доступную сторону. Текста слой не получает вовсе: в
`AgentCursorFrame` (`src/shared/types.ts`) только `visible`, `anchor` и `phase`,
поэтому подписи у указателя не будет, даже если её захочется дорисовать.

Галочка завершения — белая с синей обводкой: белая линия `--cursor-text` держит её
на тёмном контенте, синяя `--cursor-accent` — на белом.

Белый + синий здесь не декоративная пара, а способ быть видимым на любом фоне
без второго акцента.

## 2. Правила

1. **Один акцент.** Синий — для действия и присутствия: primary-кнопки, фокус,
   caret, активный пункт, ссылки, прогресс, свечение агента, индикатор записи.
   Не заливать синим большие площади и не красить им обычный текст.
2. **Белый — для текста и света.** Основной текст `--text`, вторичный
   `--text-dim`, подписи `--text-faint`. Белые блики/хайрлайны — только тонкие
   (1 px), не как фон.
3. **Семантика отдельно.** `--danger` / `--warning` / `--success` означают
   состояние, а не украшение. Ошибка — красная точка/текст, а не красная кнопка
   «ОК».
4. **Никаких новых оттенков.** Тёплые акценты (коралл, оранжевый, золотой) в
   палитру не входят; если элемент «просит» свой цвет — он просит неправильный
   токен. Исключений для курсорных слоёв нет.
5. **Контраст.** Читаемый текст — не ниже 4.5:1. Серый на сером, синий на синем,
   белый на светлом стекле — не «тонко», а нечитаемо.
6. **Одна геометрия.** Карточка — `--radius` (14), контрол — `--radius-sm` (9),
   чип/бейдж — 7. Границы — 1 px, без двойных рамок.
7. **Стекло карточки.** Поверхность образует одна заливка с непрозрачностью
   72 % в тёмной теме и 66 % в светлой. Поверх заливки лежит мягкий верхний блик.
   Тонкая рамка и тень не выходят за силуэт карточки: нативное размытие окна
   обрезано по тем же скруглённым углам, поэтому за углами не видно квадрата.
   Прозрачное окно показывает содержимое приложения под карточкой.
   На macOS фон под карточкой размывает WindowServer. Во время рисования
   размытие отключается, чтобы детали экрана оставались видны.
8. **Движение.** Вход 120–200 ms, `cubic-bezier(0.2, 0.9, 0.3, 1)`; бесконечная
   анимация — только у признака жизни (каретка, свечение агента, призрак указателя,
   столбики записи). `prefers-reduced-motion` отключает всё, кроме смены состояния.
9. **Типографика.** `-apple-system` / SF Pro. UI — 12–13 px, ответ — 15–17 px,
   бейджи — 11 px. Заголовки не капсом, кроме коротких меток.

## 3. Чек-лист нового элемента

- [ ] Цвета — только через токены, ни одного hex в компоненте.
- [ ] Акцент один: синий. Семантические цвета — только по смыслу.
- [ ] Проверено в тёмной и светлой теме (или осознанно фиксированные цвета поверх
      контента, как у свечения и метки действия).
- [ ] Читается на белом и на тёмном фоне; есть хайрлайн/тень для отделения.
- [ ] Фокус виден, `prefers-reduced-motion` учтён.
- [ ] Радиусы и отступы из шкалы, без «примерно так».
