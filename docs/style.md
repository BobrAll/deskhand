# Smart Cursor — цвета и стиль

Коротко: **белый текст и синий акцент на нейтральном стекле**. Второго акцентного
цвета нет. Новый элемент берёт токены из `src/renderer/styles/base.css` и не
вводит собственный оттенок — именно из-за этого кольцо курсора сначала выбилось
из палитры тёплым коралловым, а теперь использует тот же синий, что карточка,
рисовальный слой и индикатор «слушаю».

Документ — источник правды для цветов и базовых правил оформления. Если нужен
новый оттенок, сначала правка здесь, потом код.

## 1. Палитра

Светлая тема — не «другая палитра», а те же роли с более тёмным синим: на белом
фоне `#4a68f0` даёт нужный контраст, `#7b95ff` — нет.

### Слои у курсора

Они всегда тёмное стекло, независимо от темы: лежат поверх произвольного
контента (белый документ, тёмный редактор, фото), и светлая панель исчезла бы на
белом. Поэтому у них свои токены, но тот же синий:

| Слой | Токен | Значение |
| --- | --- | --- |
| Кольцо агента | `--cursor-accent` | `#5b78ff` |
| | `--cursor-accent-soft` | `rgba(123, 149, 255, 0.22)` |
| | `--cursor-text` | `#f4f5f7` |
| | `--cursor-surface` | `rgba(26, 27, 33, 0.86)` |
| | `--cursor-edge` | `rgba(255, 255, 255, 0.15)` |
| Индикатор «слушаю» | `--hud-accent` | `#7b95ff` |
| | `--hud-surface` | `rgba(26, 27, 33, 0.8)` |
| | `--hud-dim` | `rgba(244, 245, 247, 0.5)` |
| Рисование | `--ink` | `#5b78ff` |

Кольцо курсора — белое с синей внутренней и внешней обводкой:

- белая обводка `rgba(255, 255, 255, 0.96)` держит его на тёмном контенте;
- синяя `#5b78ff` — на белом;
- тёмная внешняя тень `rgba(0, 0, 0, 0.22)` отделяет от светлого фона.

Белый + синий здесь не декоративная пара, а способ быть видимым на любом фоне
без второго акцента.

## 2. Правила

1. **Один акцент.** Синий — для действия и присутствия: primary-кнопки, фокус,
   caret, активный пункт, ссылки, прогресс, кольцо агента, индикатор записи.
   Не заливать синим большие площади и не красить им обычный текст.
2. **Белый — для текста и света.** Основной текст `--text`, вторичный
   `--text-dim`, подписи `--text-faint`. Белые блики/хайрлайны — только тонкие
   (1 px), не как фон.
3. **Семантика отдельно.** `--danger` / `--warning` / `--success` означают
   состояние, а не украшение. Ошибка — красная точка/текст, а не красная кнопка
   «ОК».
4. **Никаких новых оттенков.** Тёплые акценты (коралл, оранжевый, золотой) в
   палитру не входят; если элемент «просит» свой цвет — он просит неправильный
   токен. Исключений для курсорных слоёв нет.
5. **Контраст.** Читаемый текст — не ниже 4.5:1. Серый на сером, синий на синем,
   белый на светлом стекле — не «тонко», а нечитаемо.
6. **Одна геометрия.** Карточка — `--radius` (14), контрол — `--radius-sm` (9),
   чип/бейдж — 7. Границы — 1 px, без двойных рамок.
7. **Стекло рисуем, а не размываем.** В прозрачном окне `backdrop-filter`
   сэмплирует пустоту: поверхность = полупрозрачная заливка + верхний блик +
   внутренний хайрлайн. Настоящее размытие — только нативное `vibrancy` у
   карточки.
8. **Движение.** Вход 120–200 ms, `cubic-bezier(0.2, 0.9, 0.3, 1)`; бесконечная
   анимация — только у индикатора активности (точка «думает», кольцо шага).
   `prefers-reduced-motion` отключает всё, кроме смены состояния.
9. **Типографика.** `-apple-system` / SF Pro. UI — 12–13 px, ответ — 15–17 px,
   бейджи — 11 px. Заголовки не капсом, кроме коротких меток.

## 3. Чек-лист нового элемента

- [ ] Цвета — только через токены, ни одного hex в компоненте.
- [ ] Акцент один: синий. Семантические цвета — только по смыслу.
- [ ] Проверено в тёмной и светлой теме (или осознанно тёмное стекло поверх
      контента, как у слоёв курсора).
- [ ] Читается на белом и на тёмном фоне; есть хайрлайн/тень для отделения.
- [ ] Фокус виден, `prefers-reduced-motion` учтён.
- [ ] Радиусы и отступы из шкалы, без «примерно так».
