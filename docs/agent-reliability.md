# Надёжность агента: цель, состояние, выполнение

## Классы ошибок

| Симптом | Класс | Что обнаружено в коде |
| --- | --- | --- |
| Повторно открывает YouTube | Потеря состояния и истории | Продолжение получало только действия последнего раунда; защиты от повторов не было |
| Останавливается до запуска видео | Преждевременное завершение | Без `@look` цикл завершался; последний доступный раунд ошибочно получал запрет действовать |
| Открывает папку вместо презентации | Подмена конечного результата промежуточным | В инструкциях не было явного различия между навигацией к файлу и открытием документа |
| Неточные действия после переходов | Рассинхронизация наблюдения и исполнения | Новый план исполнялся с исходной областью экрана; активное приложение обновлялось лишь между планами |
| Не исправляет ошибку попадания | Недостаточное восстановление | Конфликт подписи или неверный фокус безусловно завершали всю задачу |

Это причины, установленные по коду, а не трассировки конкретных пользовательских запусков.

## Новый цикл

1. Получить исходную просьбу, снимок и доступные элементы окна.
2. Выполнить короткую цепочку в пределах разрешённых возможностей.
3. Снять экран заново после паузы для отрисовки. При неудаче съёмки остановиться,
   не подставляя старую картинку.
4. Передать всю историю попыток, исходную просьбу, актуальные элементы окна и
   причину ошибки, если она была. Продолжить с достигнутого этапа.
5. `@done` вместе с действиями не завершает цикл: модель ещё не видела их результат.
   Отдельное `@done` передаёт результат на финальную проверку, если она включена.
6. Ограничить повторы и число раундов. Escape и движение физической мыши завершают
   задачу; восстановление после них не запускается.

Защита от повторов запоминает хеш изображения, область экрана и цепочку действий
в пределах одного запроса. Повтор на идентичном снимке не исполняется: агент получает
обратную связь и возможность выбрать другой способ. Повторная попытка той же
цепочки завершает запрос с объяснением. Ожидание загрузки разрешено. Финальная
проверка использует ту же память, чтобы не обойти ограничение.

Новый лимит по умолчанию — восемь раундов; сохранённые настройки пользователя
не перезаписываются. Финальная проверка имеет отдельный ограниченный бюджет:
одна попытка исправления и ещё один взгляд на результат.

## Критерии результата

| Запрос | Промежуточные состояния | Успех |
| --- | --- | --- |
| Найти на YouTube видео с котами и запустить | Главная страница, результаты поиска, загруженный плеер | Выбрано подходящее видео и видны признаки воспроизведения |
| Открыть презентацию на рабочем столе | Finder, папка Desktop, выделенный файл | Открыт нужный документ и видны слайды |
| Переключить тему macOS | Открытые настройки оформления | Видно требуемое состояние темы |

## Проверки

Автотесты с имитацией модели, снимков и исполнителя проверяют:

- многоэтапные сценарии YouTube и презентации, включая преждевременное `@done`;
- продолжение без `@look`, историю всех этапов и последний разрешённый раунд;
- смену области экрана и активного приложения;
- отсутствие продолжения по старому снимку при ошибке захвата;
- блокировку повторов и переход к альтернативному действию;
- восстановление после ошибки выбора элемента;
- отмену, ограничения ввода, недопустимость выполнения хвоста отклонённой цепочки;
- отсутствие ложного подтверждения в финальной проверке.

Команды: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`.

## Ограничения и ручная приёмка

Тесты цикла не измеряют качество распознавания реальной моделью. Защита по хешу
консервативна: часы, анимация, курсор или изменённые координаты могут сделать
логически одинаковое состояние технически другим. Общий лимит раундов остаётся
последним ограничителем. Проверка успеха по-прежнему зависит от модели и снимка.

После запуска новой сборки проверить живые сценарии: YouTube уже открыт / закрыт;
видео загружается / стоит на паузе; на рабочем столе одна / несколько презентаций;
переключение темы туда и обратно; Escape во время действия и между раундами.
Засчитывать только конечный результат, отдельно отмечая лишние открытия,
повторные действия и ошибочные заявления об успехе. Эти живые прогоны в рамках
данного изменения не выполнены.
